# 📊 Timpi Node Reward Structures

Timpi provides guaranteed minimum reward pools for each node type over fixed periods. Rewards continue beyond
the guaranteed period, with values depending on the strength of the Timpi business.

> ℹ️ Figures are per node, per month, in **$NTMPI**. This page is a reference — for how to install and run a
> node, start at the [main page](https://github.com/Timpi-official/Nodes).

## Staying eligible

Rewards depend on your node being **online and reachable**. Two things to keep right:

* **Keep your node up.** Uptime is what's measured — check yours any time with the
  [Node Checkers](https://github.com/Timpi-official/Nodes/blob/main/NodeCheckers/NodeCheckers.md)
  (`/geocore`, `/guardian`, `/collector`, `/synaptronchecker` in Discord).
* **Keep your node current.** Turn on auto-updates so you never fall behind — see the auto-update section of
  your node's guide:
  [GeoCore](https://github.com/Timpi-official/Nodes/blob/main/Geocore/README.md#s7-autoupdate) ·
  [Guardian](https://github.com/Timpi-official/Nodes/blob/main/Guardian/Tutorial/GuardianDockerLinux.md#75-enable-auto-updates) ·
  [Collector](https://github.com/Timpi-official/Nodes/blob/main/DockerCollector/Tutorial/LinuxDockerCollectorLatest.md#autoupdate).
